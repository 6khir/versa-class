# Pinned for Python 3.11 on Apple Silicon (M1/M2), CPU only.

# Version notes are load-bearing — these are not arbitrary ranges:
#
#   paddlepaddle 3.0.0  — 2.6.x segfaults (SIGSEGV) on macOS 14+/arm64 inside its
#                         dygraph kernels; even a bare Conv2D crashes the process.
#                         3.0.0 is the first release that runs clean here.
#   numpy 1.26.x        — paddle and the MobileSAM/torch stack are both built against
#                         the numpy 1.x C ABI. numpy 2.x changes that ABI.
#   opencv 4.10.x       — opencv 5.x hard-requires numpy>=2, which contradicts the above.
#
